이레 사이트 구성과 문제 추가 방법

[폴더 구성]
  index.html              첫 화면 (이레 수학 / 이레 영어)
  math/index.html         수학 학년 고르기
  math/e1.html ~ h3.html  학년별 수학 페이지 (e=초등, m=중등, h=고등, 숫자=학년)
  english/...             영어도 같은 구조
  data/math-e1.js ...     학년별 문제 파일  ← 문제는 여기만 고치면 됩니다
  assets/quiz.js          퀴즈 프로그램 (모든 학년이 함께 씀)
  assets/quiz.css         디자인
  manifest.webmanifest, sw.js, icons/   휴대폰 앱(PWA) 설정 — 고치지 마세요

[문제 파일만 직접 고쳐서 올렸을 때]
  학생 화면에는 보통 10분 안에 반영됩니다.
  바로 반영되게 하려면 Claude에게 "다시 빌드해줘"라고 하면 버전 번호를 새로 붙여 줍니다.

[학생에게 줄 주소 예시]
  https://아이디.github.io/yireh/                 첫 화면
  https://아이디.github.io/yireh/math/e3.html     초3 수학
  https://아이디.github.io/yireh/english/m2.html  중2 영어

[문제 추가]
  1. data 폴더에서 학년 파일을 엽니다. (예: 초3 수학 → data/math-e3.js)
  2. general(일반) 또는 bible(성경) 목록의 "끝"에 한 줄을 추가합니다.
     순서를 바꾸거나 중간에 끼워 넣으면 학생들의 오답노트 기록이 어긋납니다.
  3. 줄 끝의 쉼표(,)를 잊지 마세요. 마지막 문제 뒤에는 쉼표가 없어도 됩니다.
  4. 형식은 각 파일 맨 위 설명을 보세요.
     수학 수식은 $ $ 사이에 쓰고, 이 파일에서는 역슬래시를 두 번(\\frac) 씁니다.
  5. 고친 파일만 GitHub에 다시 올리면 됩니다.

[한 번에 나오는 문제 수]
  문제가 20개 미만이면 한 번에 5문제, 20개 이상이면 10문제가 나옵니다.
  문제를 늘릴수록 매주(수학)·매일(영어) 문제가 더 다양해집니다.

[로컬 LLM으로 문제 늘리기]
  파일 맨 위의 형식 설명과 기존 문제 3~4줄을 붙여넣고
  "이 형식 그대로 초3 수학 문제 10개를 한 줄에 하나씩 만들어줘"처럼 요청하세요.
  답과 해설은 꼭 직접 확인하세요.
